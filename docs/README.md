# Project Documentation

This directory will contain the documentation for the new Python-based telescope control software.

## Overview

The goal of this project is to replace the existing Matlab-based control system with a modern, web-based application written in Python.

## Features

The new software will include the following features:
- Integration with sky map software (Stellarium, Cartes Du Ciel)
- Integration with guidance software (PhD2)
- Tracking of comets and satellites
- A modern web interface
- Compatibility with the Nanomex B control system

More details will be added as the project progresses.
